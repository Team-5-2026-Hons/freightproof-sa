# client-portal

Planned read-only evidence portal for cargo owners and consignees to view trip status, the phase timeline, and downloadable evidence reports.

**Implementation status:** not scaffolded. This directory contains planning information only and must not be presented as a working application.

**Proposed stack:** Next.js, TypeScript, and Tailwind CSS, with no operational mutations.

Authentication and evidence-sharing design remain open. Earlier one-time-link proposals are historical requirements, not implemented behaviour.
