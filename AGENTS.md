# FreightProof SA — Codex entry point

Before acting in this repository, read `CLAUDE.md` in full and follow it as
project instructions. It contains the architecture, domain invariants, POPIA
rules, testing requirements, team workflow, shared-file policy, and prohibited
Git operations.

For architecture or cross-file questions, read
`graphify-out/GRAPH_REPORT.md` first and query the existing graph before opening
source files. Do not rebuild Graphify output unless you are the developer
designated to merge to `dev`; source files remain authoritative if the graph is
stale.

Keep work limited to the requested scope. Never read or print `.env` files or
secrets. Do not commit, push, merge, rebase, switch branches, rewrite history,
or discard working-tree changes.
